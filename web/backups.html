Restoring

Restore runs offline, never from this page. Stop the server, then on the server machine run:

node tools/restore.js data/backups/<snapshot>.db

The tool verifies the snapshot, keeps the current database as a -pre-restore- copy, and refuses snapshots newer than the installed code. Older snapshots are fine — pending migrations apply on the next start. Copy data/backups/ somewhere off this machine regularly; snapshots contain the full database.
