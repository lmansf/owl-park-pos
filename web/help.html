POS

Sell tickets, add-ons, memberships. Designed menu pages (or auto-grid), session picker for timed events, discount codes, cash/card split tenders, printable receipts and ticket stubs. Order search with void, full or per-line refund, and session exchange on manager approval.

admin · manager · cashier

Admissions

The gate. Scan or type a T-… ticket or M-… pass and press Enter — big OK/DENIED result with the reason. Session tickets admit from 30 min before start. Manager simulator drawer for demo scans.

all roles

Catalog → Item Config

The product list; click a row for the full-page item editor — price, tax, channels, validity, groups, live price overrides, income account. Sold items deactivate, never delete.

Groups

Item groups with colors and a two-pane product picker. Feed the menu builder, store sections, and item config.

admin · manager

Events

Timed sessions: bulk-generate a schedule (dates, times, interval, capacity), watch fill colors, raise capacity anytime — never below sold. Cancelling voids the session's tickets.

admin · manager

Menus

Design the POS screen: pages of positioned buttons — products (label/color/size) or page links. Generate from a group. No active pages = POS auto-grid fallback.

admin · manager

Store Builder

Guest store landing: hero title/subtitle/accent plus ordered sections (picked products, a group, or HTML). Empty = built-in default layout.

admin · manager

Discounts

Order-level codes, percent or amount. Same rules at POS and web checkout. Try the seeded SAVE10.

admin · manager

Pricing

Date-ranged price programs with priority. A live program changes the price everywhere at once — POS, store, carts, receipts. Highest priority wins on overlap.

admin · manager

Accounts

Chart of accounts (defaults self-install), mappings for products/tax/tenders/discounts, and a daily journal that always balances — unmapped revenue shows on 9999, refunds reverse on their day. CSV export.

admin · manager (edits: admin)

Members

Search members, view details, suspend/reinstate, print the barcode pass card. Sell and renew at POS or in the store; renewals extend the same record.

admin · manager · cashier

Reports

Sales summary, product mix, admissions, memberships — date-ranged, totals row, CSV download.

admin · manager

Backups

Database snapshots: list with sizes and triggers, back up now, delete old ones. Scheduled hourly by default, newest 14 kept. Restore is CLI-only — see the runbook in docs/user-guide.md.

A five-minute tour

  1. As cashier, sell 2 Adult + a Planetarium session on POS with code SAVE10; tender $50 cash and print the stubs.
  2. As gate, scan a ticket code on Admissions — green OK. Scan it again — red DENIED, exhausted.
  3. In the store, buy a membership (any card number approves; 4000 0000 0000 0002 declines), then scan the pass at the gate.
  4. As manager, refund the first order in POS order search, then check Reports and the Accounts journal — the day still balances.
